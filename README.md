# Project 2

## Basic Encryption & Decryption

### Description

This project was developed as part of my coursework. It implements a simple encryption and decryption technique using the **Caesar Cipher**. The program allows the user to enter text, encrypt it using a selected key, and then decrypt the encrypted text back to the original message.

### Objectives

* Understand the basic concepts of encryption and decryption
* Implement the Caesar Cipher encryption technique
* Encrypt user-provided text
* Decrypt the encrypted text
* Display the original, encrypted, and decrypted text
* Understand basic data protection concepts

### Technologies Used

* Python
* GitHub

### Encryption Technique

This project uses the **Caesar Cipher**. Each letter in the text is shifted by a fixed number of positions according to the encryption key.

For example, with a key of `3`:

```text
A → D
B → E
C → F
```

So:

```text
Hello → Khoor
```

The encrypted text can then be decrypted by shifting the letters back by the same key.

### How to Run

1. Download or clone the repository.
2. Open the Python source code.
3. Make sure Python is installed on your computer.
4. Run the program.
5. Enter the text you want to encrypt.
6. Enter an encryption key between 1 and 25.
7. The program will display the encrypted and decrypted text.

### Example

```text
Original Text:   Hello World
Encrypted Text:  Khoor Zruog
Decrypted Text:  Hello World
```

### Key Features

* Simple and easy-to-use interface
* User input for text and encryption key
* Caesar Cipher encryption
